HELMET ADVENTURE - STARTER PROTOTYPE

This is an original fan-made 2D RPG prototype inspired by classic side-scrolling MMORPGs.
It is NOT the official Helmet Heroes game and does not use official game assets.

REQUIREMENTS
- Node.js (LTS)
- Visual Studio Code
- Internet connection for the first dependency install

HOW TO RUN
1. Extract this ZIP file to a folder, such as Desktop/helmet-adventure-starter.
2. Open Visual Studio Code.
3. Choose File > Open Folder and select the extracted folder.
4. In VS Code, choose Terminal > New Terminal.
5. Type this command and press Enter:
   npm install
6. When it finishes, type:
   npm run dev
7. The terminal will show a local address, usually:
   http://localhost:5173
8. Hold Ctrl and click the address, or copy it into Chrome.

CONTROLS
- A / D or Left / Right arrows: move
- W / Up / Space: jump
- J: attack

If Windows asks whether to allow Node.js through the firewall, allow access on Private networks only.
To stop the development server, click the terminal and press Ctrl+C.

NEXT
This is only the first prototype. It currently has one player, one slime, basic HP, EXP, and leveling.
Online multiplayer, accounts, saving, trading, pets, maps, and more will need to be built separately.
